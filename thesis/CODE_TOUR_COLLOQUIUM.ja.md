## 1. 成長則と応力（Slide 7〜10）：`ansys_usermat/usermat_biofilm.f`

| 場所 | 中身 |
|---|---|
| 89 行 `subroutine usermat` | ANSYS が Gauss 点ごとに呼ぶ材料ルーチンの入口 |
| 222〜226 行 | α の積分：`ALPHA = ALPHA + KALPHA*PHI_INT`（式 36、α̇ = k_α φ） |
| 261〜267 行 | F_g = (1+α)I とその逆行列。**コードの `ALPHA` は α−1**（論文の α とは 1 ずれる） |
| 376 行 `BIOFILM_STRESS_CORE` | F_mech = F·F_g⁻¹ → F_e → ネオフックの偏差応力 2C10 (B̄ − tr/3 I) ＋ 体積の項 (2/D1)(J−1)J（4xx 行台の `TAU`、`PRESS`） |
| 330 行〜 | **接線は F を少し動かす数値微分**（Sun et al. 2008、PERT = 1e−7）。解析的ではない。差分との差は 2.4e−8 |

**一言で**：「F = F_e F_g、F_g = αI。弾性部分だけから応力を出す。α は Gauss 点で積分し、接線は F の摂動で作っています」

聞かれたら：
- 「なぜ解析的な接線にしないか」→ 摂動で十分正確（2.4e−8）。Abaqus の UMAT と同じ核を使い、両方で同じ結果になることを確認した。
- 材料定数は Gauss 点ごとに変えられる（`ustatev(11:14)` があればそれを使う、236〜250 行）。剛性 E₀(φ² + f) をどこで作るかはビルドによるので、聞かれたら「Gauss 点ごとの φ から」とだけ答える。

## 3. 各 Gauss 点の点モデル（Slide 12）：`ansys_usermat/coupling/ecology_native.f`

| 場所 | 中身 |
|---|---|
| 178 行 `eco_resjac` | 点モデルの式（Klempt 2026 の 2 本の式、障壁項込み）の残差 Q とヤコビアン |
| 271 行 `eco_solve` | Newton の 1 回分の線形解 |

聞かれたら：「点モデルだけを単独で回した結果と、連成の中の点モデルは 2e−14（Python）、1.8e−12（ANSYS）で一致した」。

## 覚え方

- 1 と 3 は「何を解いているか」、2 は「何を直したか」、4 は「どう確かめたか」。
- 数字は 4 つだけ覚える：**接線の差 2.4e−8**、**点モデルの一致 2e−14**、**人工拡散で応力が 1/4**、**内側の刻み 1e−4**。
