## 問題と解き方

Klempt 2024 の成長の場から前線の項と栄養を外した式
φ̇ = β∇²φ + k_α α、α̇ = k_α φ を、2 mm の正方形、半径 0.3 mm のシードで T* = 1 まで解く。

- **NEM**（オリバーの要素の形）：φ と α を積分点（要素あたり 2×2）に置き、Laplacian を
  近傍 12 点の 2 次 Taylor 展開＋重み付き最小二乗で求める（Rudolf et al. 2025）。
  境界の点には法線方向の微分 0 の行を足す。陽解法。
- **Galerkin**（Abaqus の UMATHT に相当）：φ を節点に置く双一次要素、整合質量、
  陰解法（後退 Euler）。α は積分点で Eq. 36。

基準は Galerkin の 256²、Δt = 0.0025。

## 分かったこと

1. **β = 0.02 では、両方ともメッシュで収束する。** シード表面の α の段差は h に比例して
   小さくなり（NEM 0.31 → 0.04、Galerkin 0.18 → 0.035、h = 0.125 → 0.016 mm）、
   両者の差も縮む。修論の「β = 0.02 でメッシュ収束」と一致する。
2. **β = 1e−4（オリバーの入力例）では、NEM の段差が収束しない。** 段差は h = 0.016 mm でも
   シード平均の 0.48 倍あり、Galerkin（0.17）の約 3 倍。拡散の長さ（√(βT) ≈ 0.01 mm）が
   要素より小さいので、NEM の場は積分点ごとの階段のまま、Galerkin の場は節点の補間で
   なめらかになる。**ANSYS（NEM）と Abaqus（Galerkin）が小さい β で違う応力を出す理由の
   候補**で、論文 P1 の中心の結果になりうる。
3. **シードの平均の α は、どちらも 1〜6 % の範囲で合う**（応力の平均は合う）。
   誤差の曲線は基準そのものの時間刻みの誤差と打ち消し合って単調でないので、
   次は時間刻みを分けて測る。
4. **時間刻み：NEM は陽解法の上限（2次元で β Δt/h_gp² ≤ 1/4）に縛られる。**
   β = 0.02 では Δt = 0.025 で 64² 以上が発散する。Galerkin（陰解法）にはこの上限がない。
   この Python の比較では、Galerkin の方が速い（力学を解いていないので、NEM の
   「連立方程式が変位だけで済む」という利点がまだ出ていない）。

## 次の一歩

- 時間刻みと空間の誤差を分けて測る（Richardson 外挿の基準）。
- 力学（成長による応力）を入れて、シードの応力のメッシュ収束を両方で比べる。
  段差の違いが応力にどう出るかが本題。
- 3次元、前線の項あり（Klempt 2024 の 4.1）。
- ANSYS（IKMHIWI03、オリバーの要素）の同じ問題の結果と突き合わせる（WP3 の実行表）。
