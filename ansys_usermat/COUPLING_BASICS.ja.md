# 連成の基礎：場の式と力のつり合いを、どう交互に解いているか

村松先生との次回ミーティング（2026年11月2日（月）日本時間17:00、ドイツ時間9:00）用。
10月5日に先生から出た質問「φ の時間発展の式と、変位のつり合いの式を、どう交互に解いているのか」に、
基礎から答えるためのノート。自分の理解の確認用も兼ねる。

---

## 1. 解いている式（何が未知数か）

Klempt et al. 2024 のモデルは、1点ごとに4種類の量を持つ。

| 量 | 意味 | 支配方程式 |
|---|---|---|
| **u** | 変位 | 力のつり合い div σ = 0 |
| **φ** | バイオフィルムの量（0〜1） | Eq. 34：φ̇ = βΔφ + k_α α − 前線項 |
| **c** | 栄養の濃度 | Eq. 35：ċ = dΔc − gφ |
| **α** | 成長の伸び（F_g = αI） | Eq. 36：α̇ = k_α φ |

つながり方（矢印は「〜が〜を決める」）：

```
c ──(前線項)──▶ φ ──(Eq. 36)──▶ α ──(F_g = αI)──▶ σ, u
▲               │
└──(消費 gφ)────┘
```

- c と φ は互いに影響し合う（栄養が φ を動かし、φ が栄養を食べる）。
- φ → α → 応力 は一方向。**応力は φ にも c にも戻らない**（Klempt 2024 は Eq. 30 の力学の項を Eq. 34 で落としている）。

ポイント：**力学（u）は場（φ, c）からの「一方通行」の受け手**。だから交互に解いても、反復で合わせ込む必要がない。

## 2. 一体解法（monolithic）と交互解法（staggered）

連成問題の解き方には2通りある。

- **一体解法**：u、φ、c、α を全部まとめて1つの大きな連立方程式にし、ニュートン法で同時に解く。
  強く結びついた問題でも安定だが、接線行列が大きく、実装が重い。
- **交互解法（演算子分割）**：場（φ, c）と力学（u）を別々に、1ステップずつ交代で解く。
  実装が楽で、それぞれに得意な解き方を使える。ただし、結びつきが強いと誤差や不安定が出る。

この研究の枠組み（Oliver の要素）は **交互解法**。

> 補足：Klempt 2024 の論文自体は、φ, c, u を1つの要素の自由度として一体で解く書き方。
> Oliver の ANSYS 実装は、力学を ANSYS に、場を自前のルーチンに分けた交互解法。
> 論文の要素は、節点ごとに変位 u、栄養 c、φ を持ち（Klempt 2024、Sec. 3）、圧力は要素内で一定（H1P0）。
> 10月5日に Soleimani 先生も「Felix の要素は φ, α, c と変位を未知数に持つ」と説明した。
> 一方、手元の Oliver の ANSYS 実装（UPF）では、場は ANSYS の自由度ではなく自前のデータ領域にあり、
> 力学とは交互に解いている。**この食い違い（論文・Felix の要素は一体、Oliver の実装は交互）を、
> 次回までに Oliver に確認しておく。**

### 交互解法でよい理由

1. **一方向だから。** 応力は φ にも c にも戻らない。力学を後から解いても場の解は変わらず、
   一体で解いても同じ答えになる。
2. **誤差を確認済みだから。** 勾配のない領域で、ANSYS の結果はその時間刻みでの厳密解と
   α で 3×10⁻¹¹ まで一致する。残る差は 1 ステップの遅れ（10/11）だけで、Δt を小さくすれば減る。
3. **双方向のステップ1・2でも交互のまま入るから。** どちらも、c や組成をステップの間で渡すだけ。
   応力が成長に戻るステップ4だけは、ステップ内の反復か一体解法が要るかもしれない（今回は範囲外）。

Oliver への確認は、交互か一体かを決めるためではない。修論に実装を正しく書くための確認。

> "The field does not depend on the stress, so solving them one after the other gives the
> same result as solving them together, up to a one-step lag that shrinks with Δt."

## 3. 1ステップの中身（Oliver の要素＋私の追加）

時刻 tₙ → tₙ₊₁ の1ステップ（Δt = 0.1、T* 単位）：

```
① ANSYS：力のつり合いを解く（ニュートン反復）
     各 Gauss 点で材料ルーチン（USERMAT）が呼ばれる
       ・φ を場から読む（tₙ の値）
       ・α を進める：αₙ₊₁ = αₙ + k_α φ Δt        ← 私の追加
       ・F_e = F F_g⁻¹、F_g = αₙ₊₁ I から応力を返す
       ・2種なら点モデルで組成を更新             ← 私の追加
     収束するまで反復（毎回 tₙ の状態から始める）

② USSFin：場を進める（力学が収束した後）
       ・c（Nut1, Nut2）：PARDISO で陰的に解く
       ・φ（Bio1, Bio2）：陽的に1ステップ更新
       → tₙ₊₁ の φ, c ができる

③ 次のステップへ（②の φ が、次の①で使われる）
```

図：修論 4 章の Figure（`flow_oliver_solution_loop.png`）と Algorithm 1。

### 押さえるべき3点

1. **順番**：力学 → 場。力学は「前のステップの φ」を使う。
2. **1ステップ遅れ**：①で使う φ は tₙ の値なので、成長は場より半歩遅れる。
   要素自身の成長変数との比 0.455 = ½ × 10/11 の「10/11」が、この1ステップの遅れ。
3. **反復はいらない**：応力が場に戻らない（一方向）ので、①と②を何度も行き来して合わせる必要がない。
   1回ずつ交代すれば十分。

## 4. 誤差と安定性（聞かれやすい）

- **時間の誤差**：交互解法の分割誤差は1次（Δt に比例）。
  厳密解（勾配のない領域の sinh, cosh）との比較で、ANSYS の結果はその時間刻みでの厳密解に
  α で 3×10⁻¹¹ まで一致している。つまり実装は正しく、残る差は時間刻みそのものの誤差。
- **場の安定性**：φ の更新は陽的なので、拡散の安定条件（Δt が h² に比べて十分小さい）がある。
  前線項を直したときに不安定になったのは、ここ（セルのペクレ数が約30）と |Δφ| の誤用のため。
- **力学は準静的**：慣性がないので、時間刻みは力学の安定性には効かない。

---

## 5. 点モデルが入るとどうなるか（2種）

- 点モデルは①の中で、各 Gauss 点ごとに呼ばれる（ブリッジ経由で Python）。
- 時計が違うので、ANSYS の Δt = 0.1 の間に、点モデルは s·Δt = 0.015 を 10⁻⁴ × 150 回で進める。
- 組成は応力に効かないので、①のニュートン反復には影響しない。
- 双方向にするなら：
  - **ステップ1**：②で解いた c を、次の①で点モデルに渡す（c* = c*₀·c）。Soleimani 先生が説明した形。
  - **ステップ2**：点モデルの組成で、②の前線項の速さ r を変える。
  - どちらも「①と②の間でデータを渡す」だけなので、交互解法のまま入る。

## 6. Gauss 点か節点か（前回の質問）

- Gauss 点：応力も成長も Gauss 点で計算されるので、点モデルもそこに置くと自然。投影がいらない。
- 節点：場（φ, c）は節点や NEM の点で持つことが多いので、節点に置く選択肢もある。
  その場合、Gauss 点の量を節点へ投影する手間が増える。
- Soleimani 先生の答え：「意図的な選択。節点でも可能」。

### 一言で言うなら（英語）

"Mechanics and the biofilm field are solved in a staggered way: in each step ANSYS
first solves the equilibrium with the field of the previous step, the material routine
grows alpha and returns the stress, and then the element advances phi and c. Since the
stress does not act back on the field, one pass per step is enough."

（力学と場は交互に解く。各ステップで、まず前のステップの場を使って ANSYS がつり合いを解き、
材料ルーチンが α を進めて応力を返す。その後、要素が φ と c を進める。応力は場に戻らないので、
1ステップに1回ずつで十分。）

## 8. 慶應での続き（候補、11月2日に1〜2個を提案）

菌種を増やすことと双方向連成のほかに、次の候補がある。おすすめ順。

1. **力学の検証（validation）。** バイオフィルムの剛性（AFM、レオメータ）や成長中の変形を測り、
   応力と比べる。修論は「verified, not validated」なので、ここが一番足りない。実験側の協力者次第。
2. **応力から成長へ（ステップ4）。** Klempt 2024 が Eq. 34 で落とした力学の項を戻す。
   本当の意味での連成で、交互解法で足りるか（反復が要るか）の議論も含めて手法の研究になる。
3. **実形状。** 歯・インプラントの形状に、CLSM で測った初期組成を置く。Abaqus への移植もここで行い、
   ANSYS 版とのクロスチェックを兼ねる。
4. **不確かさの伝播。** TMCMC の事後分布を組成と応力まで流す。「条件ごとの応力の差は、
   パラメータの不確かさより大きいか」に答えられる。道具はほぼそろっている。
5. **抗菌薬（α*、b_i）と時間変化する栄養。** Klempt 2026 の4菌種ケース3・4を場の中で行う。
   洗口や抗菌薬投与のシナリオになる。
6. **数値面。** シード表面の α の段差がメッシュで収束するか。点モデルを Gauss 点に置くか
   節点に置くかの比較。短い論文1本分。

組み合わせの案：論文にするなら 2＋6、臨床寄りなら 3＋5。研究室の得意分野に合わせて選ぶ。
