# 修論4章を β = 0.02 mm²/T* に差し替えるための対応表（10/5 作成）

決定（10/5）：修論の応力は β = 0.02（Klempt 2024 Table 2 の換算、仮定）で示し、
β = 1e−4（相方の入力例）は感度としてだけ載せる（CLAUDE.md）。
数値はすべて `results/2026-10-05_ansys/*.json` から
`python ansys_usermat/apdl/summarize_runs_json.py` で再現できる（Pa、T* = 1.1）。
修論本体はまだ書き換えていない。24³（β = 0.02）と prop(35) の実行が届いてからまとめて行う。

## 基準にする実行

- 本文の値：**8³ と 16³ の β = 0.02、dt/2（0.05）**（`ds8_beta002_dt2`, `ds16_beta002_dt2`）。
- 時間刻みの確認：dt/4（`*_dt4`）。dt/2 → dt/4 でシード p は 8³ −1.0 %、16³ −1.1 %。
- 感度：β = 1e−4（`ds8_ref`, `ds16_pv_eq36`, `ds24_pv_eq36`）と β = 0（`ds*_beta0`）。

## 注意（書くときに必要）

- **新しく動き始める点の初期値で結果が変わる。** case 6（β = 0.02、栄養なし）で、初期値 0.2 と 0.5 では
  シードの結果は 4 桁まで同じだが、0.7 にすると種 1 が勝つ（シード平均 0.95）。点モデルに二つの安定状態があり、
  その分かれ目が 0.5 と 0.7 の間にある。シードの外の組成（1 層目平均 0.28 / 0.33 / 0.58）は初期値に依存する。
  修論では「シードの外の組成は、この初期値の仮定に依存する」と明記する。prop(35) の実行で補う予定。
- 2 種のデッキの剛性は相方の入力例（1000 MPa）なので、その応力（1e+4〜1e+5 Pa）は修論に載せない。組成だけ使う。
- 換算 β = 0.02 は KLEMPT2024_REPRODUCTION.md §8 の時間・長さの換算に基づく仮定。
- **平均応力 p の余分な圧力の項（DEVIATOR_SCALING_FINDING.md、9/1 の方針どおり提出前は直さない、10/5 再確認）。**
  p を主な数値として引用する段落で、Limitations の「Pressure term」に触れる：p は ν = 0.49 で
  (1−2ν)/(1+ν) ≈ 1.3 % 大きく出る、von Mises は影響を受けない。ν = 0.45 の感度にはこの項の
  影響 6.9 % が含まれると注記する。メッシュ・時間刻みの比較は同じ式どうしなので影響しない。
