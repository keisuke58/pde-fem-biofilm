# クラウドから IKMHIWI03 へ（2026年10月14日）：方式 (c)「生きている量で成長」を固める

## 目的

10 月 19 日（月）の Oliver との会議で、結合の方式を次のように提案する（`meeting_1019_summary.tex`）：

- (a) 縮める方式（量は場、組成は点モデル、成長は Eq. 36）を基本にする。
- (c) 成長を点モデルの生きている量で決める方式（α̇ = κ Σ_i φ_i ψ_i、モード 9）を (a) の発展にする。
  点モデルの中で菌が死ぬ（溶菌、抗菌薬）と、内側から成長が下がる。Oliver の問いへの答え。

(c) は今、CH と CS の 8³ が 1 本ずつあるだけ（`results/2026-10-cal5/w8_{CH,CS}_cal_k0882.json`、
CH はシードの vM 平均が (a) より −8 %）。この指示で、(c) を会議と修論の Outlook で言える形にする。

用語：(a) = モード 7（`run_calibrated.ps1` を `-Growth` なしで）、(c) = モード 9（`-Growth`）。
κ = 8.822731e−3 は CH の T* = 1 でシード平均の成長を Eq. 36 にそろえた値（論文の値ではない）。

## A-1. 溶菌で成長が下がる（最優先）

点モデルの抗菌薬の項を入れる。全体に一定の供給（Oliver の提案どおり、一番単純な形）。

- α* と感受性 b_i：較正した θ に b が入っていればその値、0 なら Klempt et al. 2026 の例の値を使う
  （どちらを使ったかを書く）。α* は、点モデル単独（0D、CH の Day-1 から）で T* = 1 までに
  Σψ_i が基準の半分程度まで下がる値を 1 つ選ぶ（0D で数通り試して決める。強すぎて全滅しない値）。
- 仕組み：今は `run_calibrated.ps1` が BIOFILM_ECO_CASE を使わず、α* = 0（ecology_constants.py の既定）で
  走る。α* と b を要素に渡す方法を 1 つ足す（デッキの prop か、`write_eco_cfg.py --alpha-star` と
  case ファイル。後者なら theta の照合は相対許容差 1e−12 のまま）。既定は 0 のままにし、
  α* = 0 で `w8_CH_cal_k0882` と全桁一致することを確かめる。追加したら pytest も 1 本足す。
- 回すもの（CH、8³、各数十分）：
  1. (c) 抗菌薬あり → `w8_CH_cal_k0882_ab`
  2. (a) 抗菌薬あり → `w8_CH_g1_s015_ab`
- 期待：(c) は ψ が下がって成長と応力が下がる。(a) は成長が場の φ で決まるので、**α − 1 と応力が
  基準と全桁一致**するはず（組成と ψ は変わる）。一致しなければ原因を調べて報告する。

## A-5. 実測の体積に合わせた κ（14日追加、`RESEARCH_IDEAS.ja.md` §10）

実測の体積は成長の区間で 1.6〜1.8 倍（α − 1 で 0.17〜0.22）。今の κ（8.8e−3）だと α − 1 は 6.8e−4。
この差はモデルの誤りではなく、T* = 1 を 21 日とする時間の対応（仮定）と k_α の組み合わせが決まっていないため。
体積で κ を決める（時間の対応はそのまま）ために、方式 (c) の κ を体積に合わせて回す：

- CH、8³、(c)、`-Growth -Kappa 2.8 -Tag k2800`（CH の体積比 1.80 に合う見積もり）→ `w8_CH_cal_k2800`。
- 成長が大きい（α − 1 ≈ 0.2）ので、収束しないときは Δt を半分にしてやり直す（λ は変わらない、成長の項だけ）。
- 報告：シードの α − 1 の平均と、T* ごとの体積比 α³（要素の内部変数は α − 1 なので (1 + 内部変数)³。シードの Gauss 点の点モデルの記録から）を、
  実測の CH（Day 1 0.499、3 0.222、6 0.224、10 0.344、15 0.382、21 0.400、10⁶ µm³）と同じ表に並べる。
  時刻の対応は s = 0.2375（T* = 1 が Day 21）。
- 応力：シードの vM 平均を、E = 10 Pa のままと、E = 600 Pa（Pattem 2018 の下限）の 2 本で。
  デッキは `/units,MPA` なので **`-YoungBio 6e-4`**（600 を渡すと 600 MPa になる）。2 本目は
  `-Tag k2800_E600` にして、1 本目の JSON を上書きしない。
- DS は MAP が出たら同じく（`-Kappa 2.25`）。
- κ = 2.8 は体積から決めた値で、論文の値ではない。体積には剥がれなども入るので「仮定」と書く。

## A-6. 抗菌薬を途中から入れる（15日追加）

A-1 は抗菌薬を T* = 0 から一定で入れた。会議の実験案 1（成長の途中で抗菌薬を足す）に合わせ、
Fritsch et al. 2025（arXiv 2512.15145）の Fig. 18 と同じ形で、**T* = 0.5 から入れる**（それまで α* = 0、
そのあと一定。階段の形）。`JAXFEM/fritsch2025_cases.py` の `_alpha_validation_fig18` が同じ形（正規化した時間 0.5 で切り替え）。

- 仕組み：入れ始める時刻を渡す引数を 1 つ足す（例 `write_eco_cfg.py --alpha-star-on 0.5`、
  `run_calibrated.ps1 -AlphaStarOn 0.5`、T* で指定）。既定は 0 で、今の A-1 と全桁一致することを確かめる。
  点モデルの時間に直すときは s = 0.2375 を掛ける（T* = 0.5 → 0.11875）。pytest を 1 本足す。
- α*：A-1 と同じ 0.32、b_i = 1（仮定）。効きが弱く見えるなら、0D で T* = 1 の Σψ が基準の半分程度に
  なる値をもう 1 つ選び、2 本目として回す（どちらを使ったか書く）。
- 回すもの（CH、8³）：
  1. (c) → `w8_CH_cal_k0882_ab05`
  2. (a) → `w8_CH_g1_s015_ab05`
- **菌種ごとに違う b_i（15日追加）：** Fritsch の Fig. 18 では感受性の大きい菌種 4 だけが消え、残りは増える。
  b_i = 1（全菌種同じ）ではこの形が出ないので、T* = 0.5 から入れる計算を次の b でも回す
  （順番は So、An、Vei、Fn、Pg。α* は 0.32 のまま。**どれも仮定で、論文や較正の値ではない**。
  10 倍の差は Klempt et al. 2026 の例の b の幅にならった）：
  3. So だけ敏感 `-B 10,1,1,1,1`：CH で一番多い菌が減るので、(c) の成長が大きく下がるはず
     → `w8_CH_cal_k0882_ab05_So`、(a) も → `w8_CH_g1_s015_ab05_So`
  4. 嫌気性菌が敏感 `-B 1,1,10,10,10`（Vei、Fn、Pg。メトロニダゾールに近い形）：CH では Vei が 2 割ほどなので、
     成長は少し下がるはず → `w8_CH_cal_k0882_ab05_ana`、(a) も → `w8_CH_g1_s015_ab05_ana`
  （3 はクロルヘキシジンのような全体に効く薬ではなく、So を狙った仮の形。全体に効く薬は上の b_i = 1 の計算。）
  先に 0D（CH の Day-1 から）で 3 と 4 を回し、敏感な菌の ψ が落ちて全滅しないことを確かめてから要素で回す。
  全滅（Σψ がほぼ 0）するなら α* を下げた値を 1 つ選び、それを書く。
  DH の MAP が出たら、4（嫌気性菌が敏感）を DH でも回す（DH は Vei と Fn、Pg が多いので、効きが大きいはず）。
- 報告：A-1 の表に行を足す（1〜4 と、(a) のぶん）。あわせて、シードの第 1 Gauss 点の Σφψ と α − 1 の時間変化を
  抗菌薬なし・T* = 0 から・T* = 0.5 から（b の 3 通り）で比べられるよう、点モデルの記録（`_pm.json`）を push する。
- 期待：(c) は T* = 0.5 まで抗菌薬なしと全桁一致し、そのあと成長の速さが落ちる。(a) は応力が基準と全桁一致。
