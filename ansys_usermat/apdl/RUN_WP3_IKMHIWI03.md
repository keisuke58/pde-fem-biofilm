（NEM、φ は陽解法）で回す分。Galerkin 側は Abaqus（`abaqus_composition/`、UMATHT、陰解法）。

## 共通

- 形状：オリバーの 2 mm の立方体。8³ / 16³ / 24³ は `refine_deck.py --n` で細分。
  h = 0.25 / 0.125 / 0.0833 mm。
- 1菌種、β = 0.02 mm²/T*（Klempt 2024 Table 2 の換算、仮定）、k_α = 1e−3 /T*、
  E = 10 Pa（`YOUNG_BIO=1e-5` MPa）、ν = 0.49。
- 安定条件 h²/(2Δt) ≥ β を満たす Δt の上限：8³ 1.56、16³ 0.39、24³ 0.17。
  以下の Δt はすべてこの範囲内にある。

- 見込み時間は週の実行の実績から出した。1ステップあたり 8³ 0.014 分、16³ 0.24 分、
  24³ 2.5 分（`ds24_beta002_dt4`：44 ステップで 6630 s）。

  経ずに止まる：粗いので α の振幅がすぐ要素の大きさに届く）。8³ の限界は 0.088〜0.096。

  **限界のまとめ（9日）：** 8³ 0.088〜0.096、16³ 0.128〜0.160、24³ 0.158〜0.187。メッシュが粗いほど
  低い（付録 D の傾向どおり）が、8³ の値は予測 0.062 より 4〜5 割高い。E1 の 8³ の分は要らなくなった。
- **止まった実行の検知（9日、`run_wired.ps1`）。** なぜ 330 分で止まらなかったか：チェーンの START 行は
  "timeout 330 min" で、`run_wired.ps1` は `WaitForExit(330 × 60000 ms)` を1回呼んでいた。この呼び出しが
  17 時間返らず（手で殺したあと "exit −1, 61734 s"）、そのあいだ親の `ANSYS222.exe`（CPU 0 秒）と子の
  `ANSYS.exe`（CPU 393 秒、停滞）の両方が生きていた。同じシェルで `WaitForExit(3000)` は 3 秒で False を
  返すので、タイムアウト付きの `WaitForExit` が長い待ちで返らなかった理由は分かっていない。
  直し：`WaitForExit(-PollSec 秒)` のループにし、経過時間（`-TimeoutMin`）と `out_<job>.txt` の更新時刻
  （`-StallMin`、既定 60 分）を毎回見て、どちらかを超えたら `Stop-Tree` で親子とも止めて失敗にする。
  試験（8³・16段のデッキ）：`-TimeoutMin 0.3` で 24 秒で停止、`-StallMin 0.05` で 9 秒で停止、既定では
  43 秒で正常終了、残るプロセスなし。
- A の 24³、Δt 0.1 が T* = 0.8 で止まったのも同じ理由（λ = 0.29）。
- **32³ は回せない（10月8日に確かめた）。** 10月5日の 32³ は USSFin の PARDISO がメモリ不足
  （`out_ds32_pv_eq36.txt`：error −2）になり、そのあと "Not converged solution after refinements" で
  止まった。メモリは β や Δt によらないので、4点目のメッシュは足せない。シードの領域を保つには
  8³ の整数倍しか使えない（12³ や 20³ は不可）。応力の収束次数 2.1 は 3 点からの推定のままで、
  確かめる点はない。

## 安定限界の導出（10月9日、クラウド、`nem_stability.py`）

積分点の格子（要素内 h/√3、要素間 h(1−1/√3)）の上で、NEM の WLS stencil（近傍 30、
β* = 0.2 mm、しきい値 1e−8）を作り、8×8 の Bloch 記号のスペクトル半径から陽解法の限界
λ_max = 2/(ρh²) を出した。結果（`results/2026-10-wp3_fix/nem_stability.json`、
`assets/fig_nem_stability.png`、修論の付録 D）：

| | 8³ | 16³ | 24³ | 重みなし |
|---|---|---|---|---|
| 近傍 30 | 0.062 | 0.139 | 0.162 | 0.185 |
| 近傍 32（対称な殻） | 0.062 | 0.149 | 0.173 | 0.180 |
| 実行：滑らか / 振動 | ≤ 0.04 / ― | 0.128 / 0.160 | 0.158 / 0.187 | |

- Rudolf et al. の h²/(2Δt) ≥ β は1次元（3点）の条件。7点差分は 1/6。NEM は格子が不等間隔なので
  重みなしでも 1/6 にならない（0.18）。
- β* が mm で固定なので限界がメッシュに依存する。16³ と 24³ の観測区間に予測が入る。
- 8³ の約 0.06 は未検証：`IKMHIWI03_TO_CLOUD.ja.md` の依頼（β = 0.1、Δt 0.05 と 0.03）。
- 近傍 30 は距離 1.0h の 7 点（軸 6 点＋角 1 点）から 4 点を選ぶ順番が要素の実装次第なので、
  30 と 32 の両方を示す。56 近傍（しきい値まで全部）なら 0.20〜0.23。


## 参照解に対する NEM の誤差（10月9日、クラウド、`wp3_reference.py`）

A/C のシード成長（前線の項なし）は φ–α の線形系（ペナルティのみ非線形、ほぼ働かない）なので、
同じ問題を Python で高精度に解いた：2次の有限体積（7点）＋ RK4、48³ / 96³ / 192³ 格子、
シードは 8³ の 32 要素をそのまま（各格子で要素の和）。シード平均の α − 1 は 1.97 次で収束し、
96³ と 192³ の Richardson 外挿を参照解とする（残る誤差 0.05 % 未満）。参照解を NEM の各メッシュの
要素ごとに平均してから比べた（`results/2026-10-wp3_fix/wp3_reference.json`、
`assets/fig_wp3_convergence.png` 右）。

| NEM（Δt → 0 に外挿） | 8³ | 16³ | 24³ |
|---|---|---|---|
| シード平均 α − 1 の誤差 | +4.1 % | +1.3 % | +0.7 % |
| 立方体全体の要素ごとの誤差の L2 ノルム | 5.1 % | 1.9 % | 1.1 % |
| 中心 | +0.5 % | −0.3 % | −0.1 % |
| 中心から 0.4 mm（シードの縁の近く） | +5.5 % | +0.9 % | +0.2 % |
| ∫(α − 1) dV | +0.2 % | +0.1 % | +0.04 % |

- シード平均の次数は約 1.7。Δt = 0.0125 では外挿より約 0.2 % 大きい。
- 積分はどのメッシュでもほぼ合う（陽解法は φ の質量を源泉項の分を除いて保存する）。誤差は
  成長の配分（シードとその周り）に出る。
- 上の表の「中心 +1.5 %、0.4 mm +3.9 %（16³ → 24³）」は要素中心値の線形補間の偏りが大半で、
  要素平均で比べると中心・0.4 mm とも 24³ で 0.2 % 以内。修論第4章「Order of convergence」と
  5.2 の限界をこれに合わせた。

### 応力の参照（10月9日、`wp3_stress_reference.py`）

参照解の φ と α − 1 を各メッシュの要素で平均し、別の hex8 コード（B-bar、E(φ) = (φ² + f)E_bio、
f = 1e−3、ν = 0.49、三隅の拘束）で力学を解いた（`results/2026-10-wp3_fix/wp3_stress_reference.json`）。

| | 8³ | 16³ | 24³ | 48³ |
|---|---|---|---|---|
| シード平均 vM（参照の場、Python、要素ごとの値） | 5.765e−4 | 6.176e−4 | 6.143e−4 | 6.113e−4 |
| 同、積分点の値（`wp3_stress_gauss.py`、96³ の場を補間） | 4.923e−4 | 5.834e−4 | 5.982e−4 | 6.073e−4 |
| 要素自身の α − 1（Δt → 0）で解いた場合（要素ごと） | 5.544e−4 | 6.061e−4 | 6.089e−4 | ― |
| 要素の実行（ANSYS、Δt → 0） | 4.760e−4 | 5.784e−4 | 5.965e−4 | ― |

### 8³ の限界が予測より上に出た理由（10月9日、クラウド、`nem_finite_cube.py`）

- 有限の 8³ 立方体で（各点が存在する 30 近傍で stencil を作る）演算子の固有値を出しても λ_max = 0.063。
  境界のせいではない。
- 原因は初期値：φ は要素ごとに一定で、不安定モードへの成分はノルムの 8e−7。T* = 1.1 は 8³ では 18〜22 ステップ
  しかなく、1ステップの増幅 |1 − 2λ/λ_max| は λ 0.08〜0.096 で 1.5〜2.1 なので、モードが φ の大きさに届くのは
  実行の終わり近く。同じ演算子でシード問題を陽解法で進めると、α − 1 は λ 0.048 で正、0.080 でわずかに負
  （−1e−5）、0.088 から壊れる（ANSYS は 0.088 で滑らか、0.096 で停止）。
- つまり短い実行の「境目」は限界より上に出る。16³・24³ は限界近くの増幅が小さいので、境目と計算した限界が合う。
- 付録 D の本文・表・図（8³ の棒を 0.088〜0.096 に）と ch4 の時間刻みの段落を直した。
- **確かめ方（IKMHIWI03、各数十秒）：** 8³・β 0.1・Δt 0.05（λ 0.080）を T* = 5 まで（100 ステップ）回せば、
  振動するか止まるはず。Δt 0.03（λ 0.048）を T* = 5 まで回したものは滑らかなはず。
