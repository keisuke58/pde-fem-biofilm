### 2. 境界の点の重み

Oliver の NEM では、内部の点は二次（9 項）の重み付き最小二乗。表面の点は「定数 + 一次」の 4 項の当てはめに
法線方向の条件の行を 1 本（重み 1）足した重み付き最小二乗で、**一次**。この重みは温度と栄養の陰的な行列の
境界の行と、材料の指標 φ の境界値に使われている。バイオフィルムの φ の表面の点は、元の版では更新されず
初期値のまま（10/7 の件）。修正版（`F:\biofilm_upf_nativefix` 以降、cal5、hpfix も同じ）は、表面の点に
隣の積分点だけの距離の 2 乗の逆数の重み付き平均を入れる。これは 0 次で、一定の場だけ正確。

### 3. 境界の値の更新の回数

修正版は各サブステップの初めに 1 回。ただし使うのは隣の積分点だけで、表面の点どうしは使わないので、繰り返しは
要らない。重みは和が 1 なので一定の場はそのまま保たれる：下の 4 の模型で φ = 0.5 一様のとき、表面の点のずれ
2.2e−16、ラプラシアン 1e−13 以下。ANSYS での 1 ステップの計算は、指示の「1-3 以外は回さない」に従って
回していない（要るなら 8³ で数分）。元の版の材料の指標 φ も、積分点の隣だけで 1 回、和で割っている。温度と
栄養は境界の行が行列に入り同時に解くので、回数の問題はない。

### 4. NEM の演算子の自己テスト（Python の模型）

ANSYS の中で GP と表面の点に値を入れるのは手間が大きいので、同じ演算子を Python で組んだ

デッキの重み、β* = 0.2）。近傍の選び方が要素と同じかは確かめていない。表面の値を「正確」「IDW（修正版）」
「0（元の版）」の 3 通りにした。境界近く = 近傍に表面の点を含む GP（8³ で 2368/4096、16³ で 10816/32768）。

| 場 | 表面の値 | 表面の値の誤差 8³ / 16³ | ∇² の誤差 内部 8³ / 16³ | ∇² の誤差 境界近く 8³ / 16³ |
|---|---|---|---|---|
| x + 2y − z | 正確 | 0 / 0 | 6e−14 / 9e−13 | 5e−13 / 1e−12 |
| x + 2y − z | IDW | 0.48 / 0.24 | 同上 | 85 / 126 |
| x² + yz（∇² = 2） | 正確 | 0 / 0 | 4e−14 / 4e−13 | 5e−13 / 6e−13 |
| x² + yz | IDW | 0.44 / 0.23 | 同上 | 78 / 120 |
| cos πx + cos πy（無流束、max\|∇²\| 19.5） | 正確 | 0 / 0 | 0.80 / 0.45 | 1.9 / 1.0 |
| cos πx + cos πy | IDW | 0.22 / 0.057 | 同上 | 38 / 32 |
| cos πx + cos πy | 0 | 2 / 2 | 同上 | 381 / 1310 |

勾配も同じ傾向（正確なら 1e−11 以下、IDW で境界近く 2.2〜2.4）。表面の値が正確なら演算子は一次と二次の場で
丸めの範囲で正確。IDW では表面の値の誤差が一次の場で O(h)、無流束の場でも O(h²) で、ラプラシアンの重みが
1/h² なので、境界近くのラプラシアンには O(1) の誤差が残る（無流束の場で最大値の約 2 倍、細かくしても減らない）。
