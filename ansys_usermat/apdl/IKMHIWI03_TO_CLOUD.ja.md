## 頼みたいこと（ユーザーが10月7日に決めた）

1. **本体の値はそのまま。** ch4 の限界（limitations）に1〜2文を足す。内容：表面の点の φ が
   0 に固定されていたこと、直して回し直すと主な結果（シードの応力、α、組成）の変化は 0.5 % 以内
   （応力と α は 0.13 % 以内）であること。
2. **β の感度と T* = 5 は、修正した値に差し替える。** β = 0.05 / 0.1 と T* = 5 は
   `2026-10-07_surface_fix/` の JSON を使う。β = 0.02 は変わらないので今の値のままでよい。
   図を作るスクリプトがあれば、読む先を変えて図も作り直す。
3. 差し替えたら、本文で、その数字を使って書いている文（「β を大きくすると p が…」など）を
   確かめる。

守ること：
- 文書の書き方の決まり（一人称単数、強調の決まり文句を使わない、ダッシュを主な句読点にしない、
  φ / α の表記、Abaqus は修論に入れない）は `CLAUDE.md` のとおり。
- オリバーのソースの中身は書かない。「表面の点の φ が更新されていなかった」という事実と、
  直し方の説明だけにする。
- オリバーへの知らせは別にする（メールの下書きをユーザーに見せるだけで、送らない）。修論の
  文には、オリバーの名前を出して誤りを指摘する書き方はしない。
