\begin{frame}{Correction: the cylinder stresses I reported were wrong}

joined with \texttt{NUMMRG}, which merges only coincident nodes --- in the
4-condition deck, just the \textbf{4 corner nodes}. The growth layer was
essentially floating. Fixed with \texttt{VGLUE} (one shared interface mesh);
the bonded mesh converges at second order (profile error
$2.7\,\% \to 0.58\,\%$). Constants now also match the TMCMC calibration
($c^*=25$, no Hill gate, $\alpha^*=0$).
