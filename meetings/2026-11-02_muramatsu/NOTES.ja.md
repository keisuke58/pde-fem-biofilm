## 結果へのコメント（分離の例）
- **抗菌薬がどこで φ₃D に効くのか**：場の式には書いていない．点モデル（Klempt 2026 の式 16〜18，抗菌薬は α* bᵢ ψᵢ の項）で
  生きている量 Σᵢφ̄ᵢ が下がり，それが式 35 の消費を通して場に戻る．スライドに点モデルの式がないので分かりにくかった．
  → 次は点モデルの式（抗菌薬の項）を 1 枚入れる．α（成長）と α*（抗菌薬）の記号が似ていることも説明する．

  → 次回，対称性が分かる見せ方（切り取らない図，x = 0 と z = 0 の断面）を用意する．

## 対称性の確認（2 Nov，保存した 64³ の場，T* = 0.325 と 1）
- x → −x と z → −z の鏡映：φ₃D，Σᵢφ̄ᵢ，c，a，菌 A の割合はぴったり対称（差 0），応力も 10⁻¹⁰ 以内で対称．
- y → −y：対称でない（栄養が y = −1 の面からだけ来るため）．
- x と z の入れ替え：対称でない．菌 B のブロックが z に平行な辺に沿っていて，x と z が同じ役割ではないため．
  図は手前の 1/8 を切り取って x = 0 と z = 0 の断面を見せているので，この 2 つの断面の模様が違って見える．
- まとめ：計算は条件どおり x と z の鏡映について対称．見かけの非対称は，(1) 栄養が下からだけ来ること，
  (2) x と z の配置が違うこと，(3) 切り取った見せ方，による．

## 次回（11/30）に訂正・補足すること（2 Nov，文字起こしを見直して）
1. **訂正**：応力は生きている量ではなく成長 α（φ₃D から決まる）で決まり，抗菌薬の後も増え続ける．
   「変わらない」のは T* = 1 での抗菌薬あり・なしの差（約 2 %）のこと．
2. **補足**：抗菌薬は φ₃D を直接は減らさない．効く道は「生存率 ψᵢ ↓ → Σᵢφ̄ᵢ ↓ → 式 35 の消費 ↓ → 栄養 c ↑ →
   前線の速さ r c/(k+c) ↑」だけ（英語版スライドにはまだない；日本語版 4 枚目の図）．
3. **補足**：場で解いているのは φ₃D，c，a に加えて成長 α（式 36）．応力は最後に α から解く．
4. **補足**（「相互作用行列を場の式に入れればよいのでは」への答え）：Klempt 2024 の場はバイオフィルム 1 種だけ．
   種ごとに場を持たせて運ぶモデル（種を分けた連続体）は可能で，今後の課題．今回は 2 つの論文の式を変えずにつなぐことを優先した．
5. 合っていた答え：φ₃D は生死の合計，点モデルは陰解法 + ニュートン法，上下の非対称は栄養が下からだけ来るため，
   x と z は反対側から見れば対称（断面図 `assets/fig_symmetry_sections.png` で確認済み）．
