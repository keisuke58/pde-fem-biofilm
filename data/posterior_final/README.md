# 最終の事後分布の粒子と点モデルの軌道（EML、2026-10-19）

FEM で応力の予測区間を出すため。EML 側（Tmcmc202601 `tools/export_posterior_trajectories.py`、`claude/gate-off-map-check`）で書き出した。
**モデルの出力だけ**（推定したパラメータと前進モデルの軌道）。Heine らの生データ（反復ごとの値）は入っていない。

## 中身（条件ごとに `<tag>_particles.npz`、tag = CS・CH・DS・DH）

| キー | 形 | 意味 |
|---|---|---|
| `t_days` | (85,) | 共通の時刻 0〜21 日、0.25 日刻み（下の「時刻の決め方」） |
| `theta` | (200, 20) | 粒子の θ（推定と同じ並び、`theta_names`）。`free_dims` 以外は固定値 |
| `a15`, `a15_names` | (200, 15) | 相互作用行列 A の 15 成分（a11, a12, a22, a33, a34, a44, a13, a14, a23, a24, a55, a15, a25, a35, a45） |
| `phi`, `psi` | (200, 85, 5) | 体積分率 φ_i と生きた割合 ψ_i（So, An, Vei, Fn, Pg） |
| `phi0` | (200, 85) | 点モデルの空隙 φ₀ |
| `sum_phipsi`, `sum_phi` | (200, 85) | 生きている量 Σφ_iψ_i と全量 Σφ_i |
| `map_*` | | MAP（`final_theta_MAP/<tag>.json`）の同じ量、1 本 |
| `phi_init`, `psi_init` | | 初期値（Day 1 の実測から、推定と同じ） |
| `runs`, `stage` | | 元の run（3 seed）と段（CS・CH・DS は (iv)、DH は (iii)） |

- 粒子: 最終段の 3 seed の粒子をまとめて（CS・CH 15000、DS 54000、DH 60000）、一様に 200 個を間引いた（乱数 seed 0）。
  TMCMC の最終段（β = 1）の粒子は重みが等しいので、一様に間引けば事後分布からの標本になる。
- 前進モデル: 推定と同じ関数（`make_paper_figures.simulate_full`、n_steps 2500、dt 1e−4、K_hill 0）。MAP の seed の run の設定で解いた
  （3 seed で初期値と時間の設定が同じことを確かめてある）。
- 確認: MAP の生きた菌の組成の RMSE は CH 0.059、DH 0.073（EML の値と同じ）。

## 時刻の決め方

推定と同じく、初期値（Day 1 の実測）をモデル時刻 0（ここの `t_days = 0`）に置き、観測の日 d（3, 6, 10, 15, 21）は `t_days = d` に対応する
（day_scale = 0.95·n_steps·dt / 21）。図 3.2・3.6 の横軸の 1 日目とは半日〜1 日ずれる書き方なので、日をそろえるときは注意。
